# astrbot_plugin_roblox_game_search

一个 AstrBot 插件，通过 `/roblox游戏搜索` 指令查询 Roblox 游戏信息。

## 功能

- 支持按 `游戏名` 搜索。
- 支持按纯数字 `ID` 搜索，兼容 `universeId` 和 `placeId`。
- 支持直接粘贴 Roblox 游戏链接，自动提取数字 ID 查询。
- 输出单条消息，可选：
  - `HTML 生图`
  - `纯文本`
- 展示字段：
  - 游戏名 / 游戏图片 / 游戏简介
  - 开发者 / 年龄组 / 类型 / 好评度 / 价格
  - 在线人数 / 总访问量 / 收藏数
  - 公开服务器统计（状态 / 人数 / 延迟 / FPS）
  - 一键加入链接
- 内置 TTL 缓存，重复查询同一个游戏更快、更省接口额度；可用 `--刷新` 强制绕过缓存。
- 游戏名搜索未命中时，会给出相近候选及对应 ID。
- 内置收藏夹（`/roblox收藏`），按发送者持久化到 `favorites.json`，重启不丢。
- 支持代理配置，Roblox / Google 翻译接口被墙时可正常使用。

## 指令

```text
/roblox游戏搜索 游戏名
/roblox游戏搜索 https://www.roblox.com/games/2440500124/Blox-Fruits
/roblox游戏搜索 --文本 游戏名
/roblox游戏搜索 --图片 游戏名
/roblox游戏搜索 --简洁 游戏名
/roblox游戏搜索 --刷新 游戏名
/roblox游戏搜索 --排序=人数 --服务器数=5 游戏名
/roblox游戏搜索 --背景=blue 游戏名
```

### 收藏夹

```text
/roblox收藏 <游戏ID|游戏链接|游戏名>  收藏一个游戏
/roblox取消收藏 <游戏ID|游戏名>      取消收藏
/roblox我的收藏                       查看收藏列表
```

收藏数据保存在插件目录下的 `favorites.json`，按发送者区分，重启不丢失。

### 参数说明

| 参数 | 说明 |
| --- | --- |
| `--文本` / `--图片` | 输出模式：纯文本 或 HTML 生图（默认按配置，两者不能同时使用） |
| `--简洁` | 跳过公开服务器扫描，查询更快 |
| `--排序=延迟\|人数\|空位` | 公开服务器展示顺序，默认按延迟从低到高；也支持 `--排序 人数` 空格写法 |
| `--服务器数=N` | 消息内展示的服务器数量（上限 50），也支持 `--服务器数 N` 空格写法 |
| `--刷新` | 强制绕过缓存重新拉取数据 |
| `--帮助` | 显示用法说明 |
| `--背景=CSS` | 自定义 HTML 生图背景，也可用预设名：`dark` / `light` / `blue` / `red` / `green` / `purple`（支持中文名） |

复杂 CSS 背景（例如多个渐变，且包含空格）请用引号包住：

```text
/roblox游戏搜索 --背景="radial-gradient(circle at top, #2563eb, transparent), linear-gradient(135deg, #0f172a, #1d4ed8)" Doors
```

> 安全说明：`--背景` 参数会做字符校验，含 `<`、`>`、`;`、`{`、`}`、`\` 等可逃逸出 `<style>` 的值会被拒绝并回退到默认背景。

## 说明

- 本插件基于 Roblox API 调用开发。
- Roblox 游戏官网：https://roblox.com
- 会综合游戏名匹配度、赞助状态、在线人数、好评数和搜索排序选择最匹配的结果。
- 文本模式会直接发送图片组件，不再输出图片链接。
- 游戏封面图由插件自身的网络通道（走 `proxy` 配置）下载：文本模式直接发送图片字节流，HTML 生图内嵌 base64，被墙环境下不再依赖平台层或渲染浏览器直连图片 CDN；下载失败时自动回退原 URL。
- 为了保证单条消息可读性，服务器列表默认只展示排序后最适合阅读的前 `N` 个。
- 对于超大型游戏，公开服务器统计可能会在扫描上限处截断，插件会在消息底部说明。
- Roblox 公开服务器接口暂不可用时，仍会返回游戏基本信息并给出提示。
- 重复查询同一个游戏会命中内存缓存（默认 1 小时，服务器数据 3 分钟，好评率 10 分钟），可在配置里调整；需要实时数据时使用 `--刷新`。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `enable_cache` | `true` | 是否启用内存缓存 |
| `cache_static_ttl_seconds` | `3600` | 游戏详情/图片/年龄组等静态数据缓存时长 |
| `cache_votes_ttl_seconds` | `600` | 好评率（投票）数据缓存时长 |
| `cache_servers_ttl_seconds` | `180` | 服务器数据缓存时长 |
| `proxy` | 空 | HTTP(S) 代理地址，例如 `http://127.0.0.1:7897`；留空则使用系统环境变量代理 |

其余配置（请求间隔、429 重试、匹配阈值、别名等）见 WebUI 中的配置说明。

## 安装

将本目录放进 AstrBot 的 `data/plugins` 目录，然后在 WebUI 中安装依赖并启用插件。
